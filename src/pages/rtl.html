How it works

Every positional rule in app.css uses logical properties — inset-inline-start, margin-inline, border-inline-start, padding-inline — instead of physical left/right. The result: flipping the shell to RTL is a single dir="rtl" attribute on <html>.

  • Sidebar, toolbar, breadcrumbs and dropdowns mirror automatically.
  • Grid .g-row and flex flows follow the direction of the nearest dir ancestor.
  • Offcanvas slides from the other edge ([dir="rtl"] .offcanvas).
  • Monospace numbers and code stay left-aligned for scannability.
