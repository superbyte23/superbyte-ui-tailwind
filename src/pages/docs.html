Getting started

Superbyte UI is a static admin dashboard — HTML, CSS and vanilla JS. There is no build step at runtime: the generate script assembles pages from fragments, Vite bundles modules for production.

npm install
npm run generate   # assemble preview/ + index.html
npm run dev        # serve on :8765
npm run build      # production bundle → dist/
Structure
src/
├─ shell/          # app · auth · landing templates (%CON%TENT%)
├─ pages/          # page fragments + front-matter
├─ styles/         # app.css (design system) · landing.css
├─ js/             # theme · components · main + pages/
└─ scripts/        # assemble.mjs · check.mjs
public/            # fonts, brand assets, pre-paint.js
preview/           # generated app pages
index.html         # generated landing page
Theming

Theme is a set of CSS variables resolved at :root (dark) or .light. The pre-paint script in <head> applies saved prefs before first paint — no theme flash.

  • Accent — 19 colors via --accent* vars, applied on <html>.
  • Base palette — 7 neutrals via body[data-base-theme].
  • Fonts — 17 local families; --sans / --mono swap.
  • Radius — 4 / 8 / 14 px via --radius*.
  • Width & density — fluid / boxed / contained, comfy / condensed.

Prefs persist under grid_admin_* keys and restore on reload.
