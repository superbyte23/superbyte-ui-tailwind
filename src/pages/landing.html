Features

Built to be complete, not just pretty

Every page shares one consistent shell and the same design system, so what you see in the preview is exactly what you build on.

App shell

Fixed sidebar, top toolbar, global search, notifications and a user dropdown wired up and consistent across every page.

Layout modes

Vertical, horizontal and mini-sidebar navigation × fluid, boxed or contained content — all persisted via localStorage.

Theme customizer

Light/dark appearance, 19 accent colors, corner radius, font family and size, plus compact vs roomy density — saved per browser.

RTL support

A dedicated RTL preview flips the whole interface live and mirrors every layout rule.

Fast build, no bloat

Tailwind CSS v4 + Vite 6 bundle only what each page uses. Source in, static preview out, all libraries vendored locally.

Reusable components

Buttons, cards, tables, forms, modals, tabs, editors, maps and charts — a component gallery covering real admin workflows.

Theme customizer

Make it yours in seconds

The customizer ships in every page's toolbar. Pick an appearance, accent, radius and density — preferences persist via localStorage and apply instantly across the whole UI, charts included.

  • Dark / light appearance toggled from any page
  • 19 accent palettes re-color the entire design system
  • Radius, font family and base font size controls
  • Compact vs roomy density and fluid/boxed/contained widths
